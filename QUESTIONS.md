# Follow one frame

| If they ask | What you can say |
|---|---|
| Where does the signal start? | “In this demonstration I read a row from a real adult pressure-mat recording. The file and row number tell me exactly which measurements I sent. Replay gives the row a new timestamp so I can measure its journey.” |
| What does Python check? | “The service checks the device and session, the 32-by-64 shape, the 2,048 pressure values, the time and the sequence number. A malformed map gets an error. It never replaces the most recent valid result.” |
| How did the CNN learn? | “During training it saw both the pressure map and the correct posture. Each batch helped it adjust its filters to reduce errors. I used eight people for training and two different people to select the checkpoint.” |
| What does the CNN do during the demo? | “Python loads the saved weights once. Small filters slide across the pressure map to detect local patterns. The final layer combines those patterns into three scores. The largest score becomes the posture shown on screen.” |
| What did you actually measure? | “I tested on three other adults, totaling 841 frames. The CNN got 832 right, a template classifier 833, and a random forest 834. I can show the confusion matrix and an error. This evaluation covers these three positions.” |
| How do you use Firebase? | “Firebase Authentication identifies a viewer. Firestore stores the current map, prediction and frame number together. I tested that an unlisted user could not read a session and an authorized viewer could not write a sensor reading.” |
| Why does the app change by itself? | “The app subscribes to the latest document. Firestore sends the change, React Native updates its screen, and the frame number lets me match the picture to the saved result. In the video, the left and right panels show that independently.” |
| How do you recognize stale readings? | “A timer keeps checking how old the last capture is. At 3.5 seconds the status changes to stale. Losing the database subscription is a separate condition. The screen recording shows what happens when only the sensor stream pauses.” |
| What happens on a gap, retry or model error? | “The service counts skipped sequence numbers. A repeated recent frame increments a duplicate counter. A database transaction updates the current frame and recent history together. I interrupted the database connection and checked the commits after recovery. I also forced a CNN error and verified the last valid posture stayed in place.” |
| In what sense is it real time? | “New observations are processed and pushed to the screen as they arrive. In the recorded run, half of the frames were confirmed on screen within about 196 milliseconds of capture. The clocks were on the same machine. This is a measurement at the tested rate, not a timing guarantee.” |
| What remains for hardware and phone testing? | “I need a compatible mat and its controller to read a whole grid, calibrate its values and orientation, and send authenticated frames. The separate ESP32 example carries a single measurement. I still need an approved hosted Firebase project and an observed run on a physical phone.” |
